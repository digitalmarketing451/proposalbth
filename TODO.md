# Outcome Implementasi

- [ ] **US-01/US-02 — Wizard proposal dari template**: Sales dapat memilih template paket seperti BTH-3H2M, mengisi nama pemesan wajib maksimal 100 karakter, jumlah peserta bilangan bulat minimal 1, kategori/kode paket, opsi tanggal sesuai durasi, kota asal, fasilitas khusus, dan kontak klien; perubahan jumlah peserta tampil konsisten pada judul dan seluruh proposal.
- [ ] **US-03/FR-D1–D9 — Itinerary builder tervalidasi**: itinerary memiliki 1–14 hari; tiap hari memiliki lokasi, judul, aktivitas dengan jam terstruktur WITA, tipe, referensi master/teks, catatan, dan urutan; jam selesai dihitung dari durasi master; sistem memberi error untuk selesai sebelum mulai/overlap dan warning untuk gap >90 menit, flight mismatch, waktu ke bandara, perjalanan terlalu singkat, serta item makan tanpa restoran; fasilitas dan konsumsi dihitung dari aktivitas.
- [ ] **US-04/US-05/US-06/FR-E1–E10 — Pricing engine**: proposal memiliki 1–5 opsi; opsi mendukung hotel opsional, mode manual/kalkulasi, harga per orang, pax bayar/free, total = harga × pax bayar, aturan default 1 free setiap 25 pax bayar, format Rupiah, rekomendasi tunggal, jumlah kamar otomatis dari okupansi, DP dan masa berlaku.
- [ ] **US-07/FR-F1–F6 — Flight opsional**: toggle estimasi flight, input rute/maskapai/jam/harga/pax, default pax flight mengikuti total peserta, override pax wajib punya alasan, total flight otomatis, dan complimentary kosong disembunyikan.
- [ ] **US-08/FR-H1–H6 — Preview dan PDF**: preview real-time mengikuti struktur proposal A4; header branding, info klien, itinerary, opsi harga, flight, fasilitas, syarat, rekening, tanda tangan, footer; draft menampilkan watermark dan dapat dicetak/disimpan sebagai PDF.
- [ ] **US-09/US-13/US-15/FR-H4–H5/FR-I3–I5 — Share dan lifecycle**: proposal dapat disimpan sebagai draft, dibagikan melalui tautan/WhatsApp, dibuka sebagai halaman klien, disetujui klien, dan diduplikasi tanpa menyalin status/nomor/data klien.
- [ ] **FR-A1–A4/US-10/US-14 — Role dan status**: struktur peran Sales/Manajer/Admin/Owner, lifecycle Draft → Menunggu Approval → Disetujui Internal → Terkirim → Dilihat Klien → Disetujui Klien/Ditolak/Kedaluwarsa, approval saat total di atas ambang, dan ringkasan pipeline/status.
- [ ] **US-11/US-12 — Master data dan pengaturan**: halaman master untuk destinasi, restoran, hotel/rate, kendaraan, biaya tambahan, template, flight, serta pengaturan perusahaan, bank, DP, legalitas, dan footer; skema Supabase siap CRUD serta audit log.
- [ ] **BR-01–BR-12 — Konsistensi bisnis dan persistence**: pax peserta = bayar + free, durasi tanggal sesuai paket, minimal satu opsi dan satu hari itinerary, nomor proposal unik, harga terbit snapshot, zona WITA, field opsional disembunyikan, kamar dibulatkan ke atas, proposal expired tidak dapat disetujui.
